## NumPy 数组基础

1. `ndarray`是什么？ numpy数组
2. `shape`、`ndim`、`size`、`dtype`分别是什么？ 数组形状，数组维度，数组大小，数组元素类型
3. Python列表与NumPy数组的主要差异是什么？ 广播和各种矩阵功能
4. `reshape()`改变了什么？ 改变形状
5. 为什么机器学习特征矩阵通常写成`X.shape == (n_samples, n_features)`？ 方便批量计算

## Axis

1. 对二维数组而言，`axis=0`表示什么？ 表示按照列操作
2. `axis=1`表示什么？ 按行操作
3. 为什么特征标准化使用`axis=0`？ 因为每一列为不同样本的同一个特征属性
4. `keepdims=True`有什么作用？ 保持维度不变

## 索引、切片和副本

1. 布尔索引是什么？ 判断某个元素判断为true则返回该元素
2. NumPy基础切片为什么可能返回view？ 切片只是创建了一个新的“视图窗口”，指向同一块内存，而不是把数据复制一份。
3. 修改view为什么可能改变原数组？ 本质上使用的用一个元素
4. 什么时候需要显式调用`.copy()`？ 希望创建一个和原来那个元素完全无关但数值一样的新元素

## 广播与向量化

1. 广播的两个维度兼容条件是什么？ 广播的另一个维度要大小一样
2. `(n, d)`数组为什么可以减去`(d,)`数组？ 会广播
3. `X[:, None, :]`增加了哪一个维度？ 增加了axis=1维度
4. 今天哪两个函数使用了广播？ standardize_features 和 predict_nearest_centroid
5. 向量化相比Python逐元素循环有什么优势？ 速度快，方便操作

## AI数据处理

1. 为什么需要标准化？ 消除特征量纲差异，避免模型被大数值特征主导，加速训练收敛、提升稳定性。
2. 零方差列为什么不能直接除以0？ 除以0会报错
3. One-hot编码解决什么问题？ 消除分类标签的虚假数值序关系，避免模型把无大小差异的类别误判为有顺序、有距离的连续值，适配矩阵运算
4. 为什么训练集和测试集不能重叠？ 会导致正确率虚高
5. 随机种子有什么作用？ 方便复刻
6. mini-batch为什么适合训练神经网络？ 比全量更新收敛更稳定、比单样本更新计算更快，且能最大化GPU并行算力。
7. 最近质心分类器如何训练？按标签分组→逐类求特征均值得到类质心
8. 最近质心分类器如何预测？批量计算输入样本到所有类别质心的欧氏距离，返回距离最近的质心对应的类别
